# Changelog

All notable changes to **C# .NET Enterprise Suite** will be documented in this file.
The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-10-18

### Added
- **Core Architecture & Solutions:**
  - Standardized enterprise solution structure (`EniadCsharpDotnet.sln`) targeting .NET 8 / C# 12.
  - Multi-tier clean architecture: Domain, Application, Infrastructure, and API layers.
  - Comprehensive unit testing suite covering domain entities and validation rules.
  - Docker containerization manifest and multi-stage build optimization.
- **Documentation & Governance:**
  - Added `CONTRIBUTORS.md` acknowledging Oussama EL HADJI (`@Bosaj`) and open-source .NET community.
  - Full GitHub Actions CI pipeline automating build, test, and container packaging.
