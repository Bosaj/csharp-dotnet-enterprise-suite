# Academic context

## Project classification

This repository contains an academic exercise completed for the **C# and .NET module** within the course **Développement d'Applications .NET**, Semester 7, at **ENIAD**.

## Original learning objective

The original application was intentionally small. It introduced fundamental C# and .NET concepts by declaring integer variables, comparing values with `Math.Max`, and displaying the result with `Console.WriteLine`.

## Improvements made for maintainability

The original behavior remains available through the default execution path: comparing `500` and `600` prints `600`. The repository was then improved by isolating the comparison logic in a reusable class, validating optional command-line input, adding unit tests, enabling nullable reference analysis and analyzers, removing generated build artifacts, adding contributor-friendly formatting rules, and documenting local and continuous-integration build commands.

These improvements are presented as engineering enhancements to an academic exercise. They are not intended to imply that the original exercise was a production application.
